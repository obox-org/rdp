原文（keyboardhook 一节）：
  Supported values:
    0: Windows key combinations are applied on the local device.
    1: (Desktop sessions only) Windows key combinations are applied on the remote computer when in focus.
    2: (Desktop sessions only) Windows key combinations are applied on the remote computer in full screen mode only.
    3: (RemoteApp sessions only) Windows key combinations are applied on the RemoteApp when in focus.
       We recommend you use this value only when publishing the Remote Desktop Connection app (mstsc.exe) from the
       host pool on Azure Virtual Desktop. This value is only supported when using the Windows client.
  Default value: 2
