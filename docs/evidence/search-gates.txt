读法：
- `initial` = 3 张卡 + 搜索框在（占位文案 / aria-label / type=text 都对）；
- `matchChinese` / `matchSubsequence` / `matchMultiWordAnd` = 输入即过滤，中文、子序列、多词 AND 都生效；
- `multiWordAcrossEntries` / `noMatch` = 无匹配时**卡片清空 + 复用空态组件**（文案「没有匹配的连接」、**无主按钮**）；
- `afterEsc` = 真派发 Esc 后输入框清空、3 张卡恢复，顺序仍是原来的"最新在前"（3 → 2 → 1）；
- `trimmedWhitespace` = 首尾空白等价于无空白查询；
- 第二段 `empty` = **零连接**时搜索框不出现，仍是原来的空态（「还没有远程连接」+ 主按钮）。
